# LearnerTBEvalTools
Tools for evaluation parsers for learner language treebanks

Vahendid õppijakeele puudepanga parsimise hindamiseks

1. posconfusion.pl - sõnaliigi ja morfoloogilsite tunnuste vigade paaride leidmiseks.
2. includer.pl, - etteantud identifikaatorite abil alamkorpuse eraldamiseks
3. textincluder.pl - etteantud korpuse põhjal samade lausete eraldamine alamkorpusesse
4. vigadearv.sh - skript, mis käivitab järjetikused käsud vigade arvu põhjal statistka genereerimiseks.
5. veakood.sh - skript, mis võimaldab veakoodide abil eraldada alamkorpuseid ja neid hinnata.
6. sortija.pl - skript pisematest failidest lause identifikaatori järgi alamkorpuse moodustamiseks

NB! Shelli skripte on vaja kohendada oma failipuu ehitusele vastavalt, need on pigem käsujadade näidised.
